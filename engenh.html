                              Vetorização Assistida

                              Detecção automática de edifícios

                              Esta ferramenta utiliza inteligência artificial para detetar automaticamente edifícios a partir de imagens de ortofotografia. O processo é simples:

                              1. Define a área de trabalho
                              2. Anota alguns exemplos de edifícios e não-edifícios
                              3. O sistema treina um modelo e classifica a área automaticamente
                              4. Revê e aceita os resultados

                              O processamento é totalmente local — os dados nunca saem do teu navegador.
